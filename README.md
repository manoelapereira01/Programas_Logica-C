Cadastro de Alunos

Sobre o projeto

Este projeto foi desenvolvido na linguagem C para realizar o cadastro e gerenciamento de alunos.

Funcionalidades

- Cadastrar alunos e suas notas.
- Listar alunos cadastrados.
- Consultar resultados.
- Verificar aprovação ou reprovação.
- Encerrar o sistema.

Linguagem utilizada

- C

Projeto acadêmico

Repositório destinado à atividade de lógica de programação.
